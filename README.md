# Ganchillo desde cero 🧶🎀🧅

Curso de ganchillo desde cero, con Kitty y Shrek. Web estática (HTML + CSS + JS, sin build) pensada para GitHub Pages.

- 16 lecciones en 5 módulos, de la cadeneta al amigurumi.
- Solo hace falta: 2 ganchos, lanas de colores (y unas tijeras de casa).
- Progreso, notas y contador de filas se guardan en el navegador.
- Dos temas: Kitty (rosa) y pantano (Shrek). `?tema=shrek` en la URL lo fuerza.

Personalizar la dedicatoria: `js/app.js` → `DEDICATORIA`.

Probar en local: `python -m http.server` y abrir http://localhost:8000
